Deskripsi & Sasaran Pembelajaran

Penerapan sistem koordinat lokal vs world dan transformasi geometri (translasi, rotasi, skala) menggunakan matriks transformasi 3×3 yang dikirimkan ke GPU sebagai uniform pada WebGL2.

  • Menjelaskan perbedaan mendasar antara local coordinate dan world coordinate.
  • Memahami alur ruang koordinat: Local → World → View → Clip → NDC → Screen.
  • Membuat fungsi pembentuk matriks affine 2D (translasi, rotasi, skala) berformat column-major 3×3 Float32Array.
  • Memahami peran koordinat homogen 2D (x, y, 1.0) dan uniform u_matrix pada Vertex Shader.
  • Melakukan perkalian matriks untuk membentuk Model Matrix (M = T × R × S).
  • Membuktikan pengaruh urutan matriks (Transform Order Comparison: TRS in-place vs RT orbit).
  • Mengamati titik pivot origin lokal dan fungsinya dalam rotasi serta penskalaan objek.
  • Membangun hierarki Parent-Child dan satelit orbit berbasis rantai perkalian matriks.
  • Mengontrol translasi, rotasi, dan skala kontinu menggunakan state-based keyboard input dan deltaTime.

Fitur & Tantangan yang Diimplementasikan

Tugas Inti 1: WebGL2 Context & Shared GPU Geometry Buffer Selesai

Geometri segitiga lokal didefinisikan satu kali pada origin (0, 0) dalam GPU buffer (gl.STATIC_DRAW) dan digunakan bersama oleh seluruh objek tanpa memodifikasi vertex buffer pada CPU per frame.

Tugas Inti 2: Pustaka Matriks 3×3 Column-Major & Uniform Matrix Selesai

Fungsi matematika matriks 3×3 lengkap (identity, translation, rotation, scaling, multiply) berstandar WebGL (Float32Array) dikirim ke vertex shader melalui uniform u_matrix dengan koordinat homogen vec3(a_position, 1.0).

Tugas Inti 3: Continuous State-Based Input & Delta Time Selesai

Translasi (WASD/Arrow), rotasi (Q/E), penskalaan seragam (+/-), dan penskalaan non-uniform (Z/X untuk sumbu X, C/V untuk sumbu Y) dengan pergerakan kontinu dikalikan deltaTime serta pembatasan batas layar (NDC clamping).

Tugas Inti 4: Objek B dengan Animasi Rotasi & Pulsasi Otomatis Selesai

Object B berputar kontinu sebesar 70°/s dan mengalami animasi penskalaan sinusoidal berdenyut (1.0 + sin(2t) × 0.25) pada posisi tetap (0.42, 0.12) menggunakan geometry buffer yang sama dengan Object A.

Tugas Tambahan: World Coordinate Axes & Local Pivot Markers Selesai

Visualisasi garis sumbu koordinat dunia X dan Y melintasi world origin (0, 0), serta penanda titik pivot lokal pada origin setiap objek menggunakan gl.POINTS untuk memvalidasi pusat rotasi.

Challenge A: Reset Transform (Tombol R) Selesai

Mereset posisi, sudut rotasi, dan skala Object A seketika ke konfigurasi awal default (-0.38, 0.00, 0.0°, 1.00, 1.00) baik melalui tombol keyboard 'R' maupun tombol pada toolbar control.

Challenge B: Transform Presets (Tombol 1, 2, 3) Selesai

Tiga konfigurasi preset instan dengan variasi koordinat translasi, sudut rotasi, dan rasio skala non-uniform yang dapat diaktifkan via keyboard '1', '2', '3' atau tombol segmented preset.

Challenge C: Toggle Transform Order (Tombol T) Selesai

Menukar urutan perkalian matriks secara dinamis antara Mode 1: T × R × S (rotasi lokal di tempat) dan Mode 2: R × T × S (translasi ikut terrotasi mengelilingi world origin membentuk orbit).

Challenge D: Mouse Click Translation to NDC Selesai

Konversi koordinat klik piksel kursor mouse ke Normalized Device Coordinates (NDC) [-1.0, 1.0] dan mentranslasikan Object A seketika ke titik klik tersebut.

Challenge E: Hierarchical Parent & Child (Tombol J) Selesai

Objek anak hierarkis kuning terikat pada Object A sebagai parent menggunakan rumus perkalian matriks M_child_world = M_parent_world × M_child_local.

Challenge F: Simple Orbit Satellite (Tombol O) Selesai

Satelit hijau mengorbit mengelilingi objek pusat melalui rantai komposisi perkalian matriks M_center × R_orbit × T_radius × S_sat.

Fitur Tambahan: Render Freeze / Pause (Tombol P) & Speed Tuning Selesai

Fitur jeda seketika (freeze) seluruh kalkulasi render loop dan animasi via tombol 'P', serta dashboard slider interaktif untuk tuning dinamis kecepatan translasi, rotasi, dan skala.
