Deskripsi & Sasaran Pembelajaran

Modul Praktikum 5 mengimplementasikan interaksi cahaya fisik dengan permukaan objek 3D di WebGL2, memadukan perhitungan vektor normal, model refleksi pencahayaan Blinn-Phong, transformasi Matriks Normal 3×3 (invers-transpose dari Model Matrix), serta pemetaan tekstur UV dengan filter Mipmap.

  • Memahami dan menghitung vektor normal permukaan secara analitik per-face serta menormalkannya dengan normalize().
  • Mengimplementasikan tiga komponen model refleksi Blinn-Phong pada Fragment Shader:
    • Ambient: Iluminasi dasar lingkungan (intensitas dasar material Ka dikalikan warna cahaya lingkungan La).
    • Diffuse: Pantulan baur Lambertian proporsional terhadap nilai maksimum perkalian dot vektor normal (N) dan arah datang sinar (L).
    • Specular: Pantulan kilau cermin berbasis vektor separuh Blinn (H = normalisasi dari penjumlahan arah sinar L dan arah pandang kamera V) dipangkatkan nilai kilau shininess material.
  • Mengonstruksi Normal Matrix (matriks 3×3 hasil invers-transpose dari Model Matrix) untuk menjaga keabsahan orientasi normal saat objek mengalami penskalaan non-uniform.
  • Membedakan Flat Shading dan Smooth Shading secara real-time pada GLSL ES 3.00 menggunakan fungsi turunan parsial dFdx() dan dFdy().
  • Mengimplementasikan pemetaan tekstur UV 2D dengan koordinat tekstur (a_texCoord) dan texture sampler di fragment shader.
  • Mendemonstrasikan hierarki level of detail (LOD) piramida Mipmap dan membandingkan filter Nearest, Linear, serta Trilinear filtering.

Fitur & Tantangan yang Diimplementasikan

Tugas Inti 1: Normal Vektor Per-Face & Buffering Selesai

Setiap verteks kubus dilengkapi vektor normal ortogonal yang dinormalisasi pada GPU buffer Float32Array dan dialirkan ke shader via attribute a_normal.

Tugas Inti 2: Model Pencahayaan Blinn-Phong Lengkap Selesai

Kalkulasi per-fragment untuk Ambient, Lambertian Diffuse, dan Blinn Specular dengan vektor separuh Blinn (L + V yang dinormalisasi) serta kontrol eksponen shininess material.

Tugas Inti 3: Normal Matrix (Inverse-Transpose) Selesai

Transformasi vektor normal menggunakan matriks 3×3 invers-transpose dari Model Matrix, menjamin vektor normal tetap tegak lurus pada penskalaan anisotropik atau non-uniform.

Tugas Inti 4: Pemetaan Tekstur UV 2D Selesai

Atribut koordinat tekstur a_texCoord dipetakan ke setiap sisi kubus dan dikomposisikan bersama pencahayaan melalui texture(u_texture, v_texCoord).

Challenge A: 4 Tekstur Prosedural Dinamis Selesai

Empat variasi tekstur prosedural resolusi tinggi 512×512 (Checkerboard, UV Calibration Grid, Cyber Circuit, dan Sinusoidal Marble) yang dibuat secara instan di memori kanvas tanpa risiko CORS pada protokol file:///.

Challenge B: Slider Intensitas Ambient Light Selesai

Slider interaktif real-time pada Dashboard Deck untuk mengatur proporsi cahaya dasar lingkungan (0.00 s/d 1.00) dikirim via uniform u_ambientIntensity.

Challenge C: Kontrol Posisi Kamera & Cahaya Interaktif Selesai

Posisi sumber cahaya dan kamera dapat diatur secara mandiri menggunakan slider koordinat maupun pergerakan drag mouse dengan penayangan telemetri real-time.

Challenge D: Non-Uniform Scale & Normal Matrix Validation Selesai

Uji ketahanan normal matrix dengan tombol mode penskalaan non-uniform (sumbu X, Y, Z berbeda) dan saklar bypass normal matrix untuk membuktikan distorsi pencahayaan jika matriks invers-transpose tidak digunakan.

Challenge E: Animasi Orbit Sumber Cahaya Selesai

Sumber cahaya bergerak mengelilingi objek kubus secara sirkular (melingkar berbasis koordinat sinus dan cosinus waktu) disertai indikator visual kubus bercahaya kuning pada posisi cahaya.

Challenge F: Saklar Komponen Cahaya Terpisah Selesai

Tombol toggle mandiri untuk mengaktifkan/menonaktifkan masing-masing komponen Ambient, Diffuse, dan Specular secara independen untuk mengamati kontribusi fisik tiap komponen.

Challenge G: Demonstrasi Mipmap Filtering Selesai

Pemilihan mode sampling tekstur WebGL secara langsung: Nearest Neighbor, Bilinear, Bilinear with Nearest Mipmap, dan Trilinear (Linear Mipmap Linear) dengan gl.generateMipmap().
