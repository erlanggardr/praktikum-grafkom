Deskripsi & Sasaran Pembelajaran

Workflow pemodelan aset 3D hard-surface di Blender: navigasi 3D Viewport, manipulasi primitif, Edit Mode (Extrude, Inset, Loop Cut, Bevel), modifier non-destruktif (Bevel, Mirror, Array, Solidify), dan cleanup topologi mesh 3D.

  • Navigasi 3D Viewport dan penggunaan shortcut esensial Blender.
  • Pemodelan polygon hard-surface dengan Extrude, Inset, Loop Cut, dan Bevel.
  • Penerapan Non-Destructive Modifiers (Bevel, Mirror, Array, Solidify).
  • Manajemen topologi dan pembersihan mesh (topology cleanup).
  • Ekspor aset 3D siap pakai untuk pipeline tekstur dan game engine.
